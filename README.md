# Blood Donor Management System

A comprehensive web-based Blood Donor Management System with separate Admin and Donor panels.

## Features

### Admin Panel
- Dashboard with statistics
- Manage donors (CRUD operations)
- Record donations
- View donation history
- Emergency donor search
- Area-wise donor listing
- Monthly donation reports
- Upcoming eligibility reminders

### Donor Panel
- View personal dashboard
- Check donation eligibility (90-day rule)
- Update profile with image upload
- View donation history
- Emergency blood request page

## Technology Stack
- Node.js
- Express.js
- EJS Templates
- Bootstrap 5
- File-based JSON storage

## Installation

1. Clone the repository
2. Run `npm install`
3. Create `.env` file with your configuration
4. Run `npm start` or `npm run dev`
